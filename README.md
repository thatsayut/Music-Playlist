# 🎵 Music Playlist Application

A music playlist web application built with **Nuxt.js 4**.  
This application allows users to search for music tracks and view song details such as artwork, artist name, duration, and release year using the iTunes Search API.

---

## 🚀 Tech Stack

- **Nuxt.js 4**
- **Vue 3 (Composition API)**
- **Vite**
- **Vuetify**
- **iTunes Search API**

---

## ✨ Features

- 🔍 Search music by keyword
- 🎧 Display song artwork, title, and artist
- ⏱ Show track duration (mm:ss)
- 📅 Show release year
- ⚡ Server-Side Rendering (SSR) with Nuxt
- 🛡 Safe handling of undefined API fields

---

## 📱 Responsive Design

The application supports responsive design for mobile, tablet, and desktop devices using Vuetify's grid system and breakpoints.


## 📦 Requirements

- **Node.js** v18 or higher  
- **npm** or **pnpm**

```bash
node -v

Install dependencies
